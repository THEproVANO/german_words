# Идеи на доработку

## Сделано
- Сводка после теста дня: изучено сегодня и всего, результат теста.
- Итоги недели после недельного теста: изучено за неделю, темп при текущих настройках, прогноз.
- Команда `/quiz` для администратора, чтобы проверять тесты без ожидания 22:00.
- Вопрос после выбора уровня: только этот уровень или вместе с уровнями ниже.
