# Переводы слов на другие языки бота

`<язык слов>_<язык бота>.csv`, например `de_es.csv` — немецкие слова с переводом на испанский.
Строка: `ключ;переводы;перевод примера`. Ключ — как в базе: `de:noun:der:Apfel`,
для тематического набора — с префиксом `BIZ:`.

Пользователь с испанским интерфейсом получает только слова, у которых есть испанский перевод.
