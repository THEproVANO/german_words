# Контекст проекта для продолжения работы (передача другому ИИ)

Этот файл описывает проект целиком: что сделано, как устроен код, какие решения приняты и почему.
Его можно передать любому ИИ-ассистенту, чтобы сразу продолжить работу.

## 1. Что это

Telegram-бот для изучения иностранных слов: **немецкий, английский, испанский**, уровни **A1–C2** плюс
тематический уровень **«💼 Работа, бизнес и IT»**. У каждого пользователя свой аккаунт и прогресс.

- Репозиторий: https://github.com/THEproVANO/german_words (ветка `main`, работаем прямо в ней).
- Владелец общается **на русском**, сам не программист: объяснять просто, давать готовые команды.
- Сервер: VPS, Ubuntu 24.04, пользователь `bot`, бот запущен как systemd-сервис `german-words-bot`.
- Обновление сервера (владелец делает сам через веб-консоль хостинга):
  ```
  su - bot
  ~/german_words/deploy/update.sh
  ```
  (`git pull` + `pip install` + `systemctl restart`).
- Токен бота — только в `.env` на сервере (в git его нет и никогда не должно быть). Там же `ADMIN_IDS`.

## 2. Как бот работает (для пользователя)

1. `/start` → выбор **языка бота** (🇷🇺 Русский / 🇬🇧 English / 🇪🇸 Español; французский был и удалён).
2. Выбор **изучаемого языка**. Родной язык бота не предлагается (при английском интерфейсе нельзя
   учить английский и т. п.). Языки без словаря/перевода скрыты.
3. Выбор **уровня** (A1…C2 по три в ряд, отдельной строкой «💼 Работа, бизнес и IT»).
   Для A2–C2 вопрос: присылать только этот уровень или вместе с уровнями ниже. Для A1 и темы — без вопроса.
4. Правила + первое слово сразу. Дальше слова приходят **по одному каждые 30 минут** с выбранного часа.
5. **Карточка слова**: флаг изучаемого языка, часть речи, уровень; слово (у существительных — артикль и
   мн. ч.; у глаголов — формы); 1–3 перевода с флагом языка перевода; пример со словом жирным и перевод примера.
   - de: `der Apfel, die Äpfel`; глагол `fahren (er fährt) — fuhr — ist gefahren`
   - en: `child, children`; глагол `go — went — gone`
   - es: `la mano` (мн. ч. НЕ показываем — по совету: образуется по правилу); глагол
     `tener (yo tengo) — tuve — tenido`. Отмечаются только «нет мн. ч.» (`-`) и «только мн. ч.» (`pl`, тогда `las vacaciones`).
6. Кнопка **«➕ Ещё слово»** — слово вне расписания (в дневной лимит не входит).
7. **Тест дня** в выбранное время: до 10 случайных слов за день. Бот пишет перевод + часть речи +
   первую букву, пользователь вводит слово. Нестрогое сравнение: регистр; артикли (der/die/das, a/the,
   el/la/los/las/un/una) и `sich`/`to` не обязательны; ä→ae и т. п.; ударения и ñ в испанском не обязательны;
   апостроф не обязателен. Синоним с тем же переводом — не ошибка (бот подсказывает). После 2-й ошибки —
   подсказка, после 3-й — кнопка «Показать ответ» (слово уходит в конец теста).
   **Пока тест не пройден, новые слова не приходят.**
8. После теста дня: «🎉 пройден» → **сводка** (изучено сегодня/всего, %, статистика теста) →
   **список слов за день с переводами** («📚 Слова за сегодня»).
9. По воскресеньям после теста дня — **недельный тест** (до 40 слов) + итоги недели (темп, прогноз окончания уровня).
10. **Профиль**: язык, уровень, прогресс, расписание, часовой пояс, язык бота, статус. Кнопки:
    «📬 Рассылка и тест», «🕒 Часовой пояс», «📚 Сменить уровень», «🌍 Изучаемый язык», «🌐 Язык бота»,
    «ℹ️ Как работает бот», «⏸ Пауза», «🔄 Перезапуск (для обновления версии бота)».
11. **«📬 Рассылка и тест»** — три шага: начало (8:00–12:00) → число слов (5–30, показываются только
    варианты, при которых последнее слово ≤ 21:30) → показ «начало / слов / последнее слово» и выбор
    **времени теста с шагом 1 час** (от ближайшего часа ≥ последнее слово + 30 мин до 22:00).
12. Каждое полученное слово считается изученным. Слова не повторяются; слово, уже полученное в другом
    наборе (например A2 и «Работа, бизнес и IT»), второй раз не приходит и засчитывается.
13. Тесты/сводки берут слова **только текущего изучаемого языка** (был баг со смешиванием — исправлен).
14. Команды: `/start`, `/id` (свой Telegram ID), `/quiz` и `/quiz week` — пробный тест (только для `ADMIN_IDS`).
15. После обновления с новой `BOT_VERSION` бот сам рассылает всем «🔄 Бот обновлён» + свежее меню +
    описание изменений (`whats_new_<версия>` в i18n). Писать /start не нужно.

| 🇪🇸 es | 🇪🇸 | 🇪🇸 | — (свой язык) |

Основные переводы (русские) — в словаре. Переводы на en/es — отдельные файлы `data/translations/<язык слов>_<язык бота>.csv`.
Пользователь с en/es-интерфейсом получает **только слова, у которых есть перевод на его язык** (русский ему не показывается).
Все переводы сейчас заполнены на 100%. Переводили с оригинала (de/en/es), русский — только подсказка значения.

## 5. Код (Python 3, aiogram 3, SQLite)

```
bot/
  __main__.py   запуск: загрузка словарей, polling, планировщик, рассылка «бот обновлён»
  config.py     константы: LEVELS, TOPICS=["BIZ"], LANGUAGES=["de","en","es"], TRANSLATION_LANGS=["en","es"],
                WORD_INTERVAL=30, DAY_START=9, WORDS_PER_DAY=15, QUIZ_TIME=22*60, DAY_START_OPTIONS=8..12,
                WORDS_PER_DAY_OPTIONS, LATEST_QUIZ_TIME=22*60, DAILY/WEEKLY_QUIZ_SIZE=10/40, TIMEZONES, BOT_VERSION
  db.py         sqlite3 (WAL), схема + миграции через PRAGMA table_info/ALTER TABLE; функции работы с данными
  i18n.py       TEXTS[key][ru|en|es], t(lang, key, **kw), POS_NAMES, CITIES, level_name()
  keyboards.py  клавиатуры (reply-меню и inline)
  handlers.py   обработчики команд/кнопок (Router)
  service.py    расписание, отправка слов, тесты, сводки, планировщик (тик 30 с), notify_update
  words.py      загрузка CSV в БД, карточка, нормализация ответов, синонимы, переводы, флаги
data/
  de_words.csv, en_words.csv, es_words.csv     словари (разделитель `;`)
  translations/{de_en,de_es,en_es,es_en}.csv   переводы: ключ;переводы;перевод примера
tools/vocab/      SPEC_{de,en,es}.md (формат строк для генерации), add_words.py (проверка + добавление партии)
tools/translate/  split.py / check.py / merge.py + INSTRUCTIONS(.md|_en.md) — процесс перевода на язык бота
deploy/           german-words-bot.service, update.sh
```

**Формат словаря** (`;`): `level;pos;article;word;plural;praesens;praeteritum;perfekt;translations;example;example_ru`
- `pos`: noun, verb, adj, adv, prep, pron, conj, num, part, interj; `level`: A1…C2 или BIZ.
- В примере слово выделено `**…**`. `plural`: `-` — нет мн. ч., `pl` — только мн. ч.
- de: article der/die/das; praesens `er fährt` (только если корень меняется); perfekt `ist gefahren`.
- en: article пустой; praeteritum/perfekt = Past Simple / Past Participle.
- es: article el/la; plural пустой (кроме `-`/`pl`); praesens `yo tengo`/`me duele` (только неправильные).
- Ключ слова в БД: `lang:pos:article:word`, для BIZ — с префиксом `BIZ:` (тема может повторять слова уровней).
- Словари загружаются в БД при каждом старте (upsert по ключу).

**Таблицы БД**: `users` (lang, level, include_lower, ui_lang, tz, day_start, words_per_day, quiz_time,
last_slot_date/idx, paused, blocked, seen_version; устаревшие interval_min/day_end не используются),
`words` (+ translations_en/es, example_en/es), `user_words` (study_date), `quizzes`, `quiz_items`.

**Ключевая логика**
- Слоты: `day_start*60 + i*30` для i < words_per_day, только < quiz_time. Один слот за тик, пропущенные не догоняются.
- Учебный день: слова после времени теста относятся к следующему дню. Тест дня = за учебный день «вчера».
- Смена настроек расписания → `reset_schedule` (наступившие слоты считаются отправленными, чтобы не было лавины).
- `tr_lang(user)`: язык переводов = язык бота, если он в TRANSLATION_LANGS и не равен изучаемому, иначе ru.
- Пер-юзер asyncio.Lock против гонок между планировщиком и обработчиками.

## 6. Как проверяли

Без реального Telegram: симуляции с фейковыми Bot/Message/CallbackQuery (вызов хендлеров напрямую,
подмена `service.local_now` для управления временем) + `pyflakes`. Проверять так же после изменений
(создать временную БД через `DB_PATH=...`).

## 7. Принятые решения и пожелания владельца

- Слова — случайные из выбранного уровня (и ниже, если выбрано). 15 слов/день по умолчанию.
- Качество переводов важнее скорости; переводить с оригинала, не через русский.
- Испанские существительные — без мн. ч. (только el/la), глаголы — «как в немецком».
- Кнопка «Перезапуск» — обновляет меню/профиль у пользователя (не перезапускает сервер).
- Изменения, заметные пользователям → поднять `BOT_VERSION` и добавить `whats_new_<N>` на 3 языках.
- Коммитить и пушить в `main` после каждого шага; в конце давать владельцу команды обновления сервера.
