# Пополнение словарей

- `SPEC_en.md`, `SPEC_es.md` — формат строк для английского и испанского словаря.
- `add_en.py`, `add_es.py` — проверяют партию слов и дописывают в `data/<lang>_words.csv`,
  пропуская слова, которые уже есть (по части речи и слову).

```bash
python3 tools/vocab/add_en.py batch.csv
```

Партии добавлять от младших уровней к старшим: при совпадении слово остаётся на первом уровне.

## План C1–C2 (в работе)
Цель: английский C1 ~1200, C2 ~1000; испанский C1 ~1000, C2 ~900.
Текущее состояние — по количеству слов уровней C1/C2 в `data/en_words.csv` и `data/es_words.csv`.
