# Пополнение словарей

- `SPEC_de.md`, `SPEC_en.md`, `SPEC_es.md` — формат строк словарей.
- `add_words.py` — проверяет партию слов и дописывает в `data/<lang>_words.csv`,
  пропуская слова, которые уже есть (по части речи и слову). Тематический уровень BIZ
  («Бизнес и IT») проверяется на дубли только внутри себя.

```bash
python3 tools/vocab/add_words.py en batch.csv   # de / en / es
```

Партии добавлять от младших уровней к старшим: при совпадении слово остаётся на первом уровне.
